# 🧠 React Task - Backend

Este é o backend da aplicação **React Task**, uma API RESTful desenvolvida em **Node.js** com **Express**, responsável por gerenciar tarefas (to-do list) e conectar com o frontend React.

---


---

## 🚀 Tecnologias Utilizadas

- **Node.js**
- **Express**
- **MongoDB** + **Mongoose**
- **dotenv**
- **cors**
- **nodemon** (para desenvolvimento)
